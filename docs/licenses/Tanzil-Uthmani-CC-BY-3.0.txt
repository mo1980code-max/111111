This notice covers the Quranic Arabic text shipped in this repository at:

    app/src/main/assets/databases/quran.ar.uthmani.db
        table `arabic_text` (sura, ayah, text) -- 114 surahs, 6236 ayahs

and the surah names mirrored into:

    app/src/main/java/com/clock/livewallpaper/quran/SurahIndex.java
        ARABIC_NAMES[]

The database is a verbatim, unmodified copy of the Tanzil text. Per the Tanzil
terms of use, the text is redistributed unchanged: no diacritic removal, no
normalisation, no re-ordering, and no automatic insertion of the basmallah into
ayah text. The surah/ayah keys are the Hafs numbering.

--------------------------------------------------------------------
Reproducing the asset
--------------------------------------------------------------------

The database is generated, never hand-edited:

    python3 tools/build_quran_db.py

That script re-downloads the Tanzil XML, verifies the copyright block, the
114/6236 structure and every per-surah ayah count, then writes and independently
re-verifies the .db. Pass --xml <path> to rebuild without network access.
